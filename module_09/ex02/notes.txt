**The idea

 Will do the follow :) 
	->	INPUT
 
	->	PARSE

	->	PAIR ELEMENTS
	
	->	ORDER EACH PAIR (big, small)

	->	MAIN CHAIN = all bigs
	->	PEND       = all smalls

	->	SORT MAIN CHAIN

	->	INSERT PEND with binary search

	=	FINAL SORTED RESULT 


 flow of the program when running =

 run()
 ├── parseInput()
 ├── sortVector()
 │     └── fordJohnsonVector()
 │           ├── makePairs()
 │           ├── split (implicit in pairs)
 │           ├── sort main chain
 │           └── insert pend
 └── sortDeque()
